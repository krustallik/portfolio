# Public repository audit

Date: 4 November 2026
Account: [krustallik](https://github.com/krustallik)
Scope: portfolio content selection only. No other repository was modified.

## Method

I enumerated all 15 public repositories through GitHub's public repository API and checked each current default branch, description, README, recursive file tree, available dependency/build manifests, representative implementation files, screenshots and documentation, and the latest three commit summaries. Source links below use the latest observed commit where a commit is relevant. This is a content and portfolio audit, not a full code or security review.

## Selection summary

- **Six featured case studies:** public lighting, Booktop, GymBeam Shifts, BodyCast, building management, and the co-authored missing-data study.
- **Five compact additional links:** Northline, MVS Skills, citizen reporting, personal spending log, and Chess.
- **Two research links:** OpenFOAM and Modulus, with the current-run boundary visible beside them.
- **Not selected:** the small Tkinter puzzle app and the third-party `feedaily` fork. The Marketplace fork was retained because its README documents a distinct project and the owner's frontend contribution.

No live demo was inferred from deployment files. BodyCast was opened with a read-only GET and reached its public sign-in page; no account was entered. GymBeam's repository explicitly says it has no public demo URL or account. The building app's README documents a public walkthrough; the exact link returned HTTP 200.
